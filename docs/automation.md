# 自动化任务

控制台的“自动化”页面保存每个用户自己的渠道观测任务。任务包含来源、API key、模型、统计窗口和检测周期；策略文档保存指标选择、样本门槛、置信水平、分位数、改善幅度、连续确认次数、冷却时间、最多移动数量和执行方式。

任务每 20 秒由后端调度器领取，到期任务通过 DuckDB 查询最近窗口的渠道事实。任务可以在执行前并发发起 `gpt-6-astra` 降智检测；成功率、缓存率和不降智概率使用 Wilson 区间，首字延迟可选择 p50 或 p95。未达到样本门槛、置信区间差异和最小改善幅度时不会产生候选变动。非 `gpt-6-astra` 任务忽略不降智指标。

渠道 A 只有在所有选定指标都满足阈值，并且（开启该选项时）全面支配所有更高优先级渠道，才会被逐步上移。任务默认只生成建议。自动应用要求指定 API key，并使用当前 `revision` 提交 uni-api 临时控制；冲突或上游拒绝时不会覆盖人工修改。

每次运行都会写入审计：状态、前后顺序、移动关系、指标快照和原因。连续确认和冷却时间在后端执行，前端参数只是配置入口；历史审计不会因为任务删除而泄露到其他用户，任务删除会级联清理该任务的审计记录。
