# Kimi K3.1 Pro

Added `kimi-k3.1-pro` to the shared model catalog on 2026-10-24. Channel
management filters, built-in detection choices, batch selection, import model
lists and price settings consume this same catalog. Existing operator prices
and saved model exclusions are preserved. Adding the model does not start a
sync or a probe.

The official [model guide](https://platform.kimi.ai/docs/guide/kimi-k3-1-pro-quickstart)
confirms the exact model ID. The [pricing page](https://platform.kimi.ai/docs/pricing/chat)
currently exposes empty K3 price tables in both its HTML and Markdown response.
Its [cache guide](https://platform.kimi.ai/docs/guide/context-caching) confirms
separate 5-minute and 1-hour writes, but provides numeric examples for K3 only.
No K3 price is copied into K3.1 Pro. The new entry is unverified with empty price
inputs in the UI and is excluded from reference-cost estimation until confirmed.
