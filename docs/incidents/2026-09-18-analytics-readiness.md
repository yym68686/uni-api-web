## 修复

- `REQUIRE_INITIAL_IMPORT=true` 时，在 `startBackground` 之后等待历史统计就绪，再绑定公开 HTTP 端口。TCP 探针只能在可以提供统计时成功，滚动发布期间由旧 ready 实例继续服务。
- 检测、账单与配置恢复 worker 仍在等待前启动；不重新引入检测任务等待历史预热的问题。
- 可选查询预热仍不阻塞流量就绪。
- 收到初始化响应时，前端显示同一 query 的上次成功数据并标记旧数据；不同 Key/时间条件不能借用另一 query 的缓存。
- 已确认初始化时不再同时显示“请检查 S3 导出配置”的无关提示。
