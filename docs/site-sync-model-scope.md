# 站点账号批量同步的检测范围

「一键同步并检测」同步所有空闲账号的分组、专用测试 key 和模型目录，检测只使用点击时「检测模型设置」的勾选快照，不使用渠道列表的账号、模型或可用性筛选。没有勾选模型时禁止提交。

可用性、Astra 降智、自动指纹、压缩及 Tool use 阶段均受此快照约束；各检测仍遵循原有模型适用条件。未勾选模型的历史结果保留，站点新发现但未勾选的模型仅加入目录。提交后的设置变更仅影响下一批任务。

单账号「同步并检测」和新账号初次同步维持原行为。显式单模型检测仍直接检测所选模型。

前端通过 `POST /v1/sub2api/accounts/sync-selected` 发送非空 `models` 数组。旧后台未提供此端点时提示服务待更新，不回退到全模型检测。旧 `/accounts/sync` 入口也要求非空模型数组，拒绝缺失或空范围。

范围以 `console_sub_accounts.sync_models` 与任务原子入队，由实际执行任务的 worker 读取；不依赖 HTTP 请求上下文、浏览器状态或单个实例的内存。使用原有账号 lease、停止机制和指纹站点并发限制。
